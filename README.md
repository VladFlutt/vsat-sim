# Тренажёр VSAT

Интерактивный тренажёр по установке и настройке VSAT-терминала. Страница `index.html` работает без сборки; ИИ-функции работают через serverless-функцию `api/ai.js` на Vercel.

Опубликован на Vercel: https://vsat-sim.vercel.app

## ИИ-инструктор

Вкладка «ИИ-инструктор» и кнопка «Разбор ИИ-инструктора» под итогом каждой практики. Функции:

- разбор завершённого наряда по журналу действий;
- ответы на вопросы по материалам курса;
- проверка фото реального монтажа (антенна, разделка кабеля, заземление, индикаторы модема);
- персональный план подготовки к экзамену по результатам в браузере.

Модель: Claude (`claude-opus-5-5`) через `@anthropic-ai/sdk`. Для работы в настройках проекта Vercel нужна переменная окружения `ANTHROPIC_API_KEY`. Без неё тренажёр работает как раньше, а ИИ-функции показывают сообщение, что они не подключены.

База знаний ИИ (`api/_kb.js`) собирается из теории тренажёра: `node scripts/build-kb.cjs` (нужен Playwright). После правок теории в `index.html` её нужно пересобрать.

## Запуск локально

Откройте `index.html` в браузере. ИИ-функции локально работают только через `vercel dev` с заданным `ANTHROPIC_API_KEY`.
