# Тренажёр VSAT

Интерактивный тренажёр по установке и настройке VSAT-терминала. Это одна статическая страница (`index.html`), без сборки и зависимостей.

Опубликован на Vercel: https://vsat-sim.vercel.app

## Запуск локально

Откройте `index.html` в браузере.

## Материалы

- `docs/Методика настройки.docx` — методика настройки, по которой построен тренажёр
- `docs/GVF_VSAT_Install_and_Maint_Handbook_Level3_Rev1_31_OB.pdf` — справочник GVF по установке и обслуживанию VSAT
